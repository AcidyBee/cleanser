# Keep empty columns

Keep empty columns

## Usage

``` r
keep_empty_col(data)
```

## Arguments

- data:

  A dataset where empty columns are to be extracted

## Value

a data frame with the same number of rows as the imput data, but keeping
only the empty columns.

## Examples

``` r
if (FALSE) { # \dontrun{
data_D_raw %>%
  keep_empty_col()
} # }
```
