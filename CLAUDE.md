# cleanser

R package of utility functions to check, clean and prepare a dataset.
Not yet on CRAN (version 0.0.0.9000).

## Language

- Write all documentation, code comments, messages, errors and commit
  messages in English.
- Talk to the maintainer in French in the conversation.
- Some existing code comments are still in French and are being
  translated.

## Design

- Follow the tidyverse style guide (<https://style.tidyverse.org>) and
  the tidy design principles (<https://design.tidyverse.org>).
- Functions that work on a data frame take it as their first argument
  and return a data frame, so they work in a pipe.
- Column-selection arguments accept tidyselect syntax (`{{ }}`,
  [`tidyselect::eval_select()`](https://tidyselect.r-lib.org/reference/eval_select.html)),
  not only character vectors.
- Use snake_case, no abbreviations in exported names (`with`, not `w`).
- Call functions from imported packages as `pkg::fun()`.
- Write error messages as the tidyverse style guide describes (say what
  went wrong and where).

## Naming

- Every exported function uses the `cln_` prefix and the order
  `cln_verb_target_criterion()`,
  e.g. [`cln_keep_col_numeric()`](https://acidybee.github.io/cleanser/reference/cln_keep_col_numeric.md),
  [`cln_discard_row_empty()`](https://acidybee.github.io/cleanser/reference/cln_discard_row_empty.md),
  [`cln_keep_col_with_levels()`](https://acidybee.github.io/cleanser/reference/cln_keep_col_with_levels.md).
- `clr_` is the old prefix: do not use it (it clashes with the prismatic
  package and with “centered log-ratio”).
- The re-exported pipe `%>%` keeps its name.
- Verb families: `keep_` / `discard_` (return the data with the columns
  or rows that match / do not match a criterion), `detect_`, `is_`,
  `has_` (return logicals), `extract_` (return the rows that do not
  match expectations), `fix_` (correct values), `recode_`, `classify_`,
  `split_`, `compute_`, `compose_`, `convert_`, `create_`, `translate_`,
  `round_`.
- The package is not released yet: renames need no deprecated aliases.

## Tooling

- Document with roxygen2 in markdown; every exported function has
  `@examples`.
- Test with testthat (3rd edition); add or update tests with every
  change.
- `NAMESPACE` and `man/` are generated by `devtools::document()`. R is
  not available in cloud sessions: when a rename forces edits there,
  keep them strictly mechanical and ask the maintainer to run
  `devtools::document()` locally.
- Before saying a change is done: `devtools::document()`,
  `devtools::test()`, `devtools::check()`.
- Keep `CLAUDE.md` listed in `.Rbuildignore`.

## Vignettes

- Structure: introduction (the problem solved, 2–3 sentences); a small
  example dataset covering every case; the functions grouped by task
  (check → extract → recode), each shown with one example and one
  sentence; optional “How it works” section for internals.
- Name the arguments in examples (`id_cols = "id"`, not `"id"`).
- Example data in English. No commented-out code or development notes.
- `vignettes/factor.Rmd` is the reference model once it has been
  rewritten.

## Working rules

- Do not change a function’s behaviour unless the maintainer asks;
  propose the change first.
- One kind of change per commit (rename, translation, behaviour fix).
- For wide changes (renames, refactors), show the plan first, e.g. an
  “old name → new name” table, and wait for approval.

## Known issues and pending decisions (do not act unless asked)

- The `cln_extract_mismatch_*` functions do not accept tidyselect
  `id_cols`, unlike `keep_` / `discard_`.
- The code uses `\(x)`: DESCRIPTION needs `Depends: R (>= 4.1.0)`.
- Commented-out code in `R/join.R` and `R/mutate.R`.
- Tests exist only for `dummy` and `factor`.
- [`cln_is_shared_values_across_rows()`](https://acidybee.github.io/cleanser/reference/cln_is_shared_values_across_rows.md)
  is defined twice, identically, in `R/join.R` and `R/unite.R`: keep
  one.
- [`cln_split_median()`](https://acidybee.github.io/cleanser/reference/cln_split_median.md)
  duplicates
  [`cln_classify_median()`](https://acidybee.github.io/cleanser/reference/cln_classify_median.md)
  (only the `na.rm` default differs): decide which one to keep.
- [`cln_recode_col_non_oui()`](https://acidybee.github.io/cleanser/reference/cln_recode_col_non_oui.md)
  is French-specific: planned to become a documentation example of
  [`cln_recode_col_with_levels()`](https://acidybee.github.io/cleanser/reference/cln_recode_col_with_levels.md) +
  [`purrr::partial()`](https://purrr.tidyverse.org/reference/partial.html)
  instead of an export.
- Doc titles to fix: `cln_map_mismatch_cols_with_suffix` reuses the
  title of `cln_extract_mismatch_2cols`;
  `cln_create_lut_from_dictionary` title does not describe it; typo
  “jon” in `cln_left_join_fuzzy_date`.
